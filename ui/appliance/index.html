照片与录像

登录后加载 SD 卡媒体。

    照片可直接预览。AVI 包含 MJPEG 视频和 PCM 音频，请下载后用兼容播放器打开。录制期间可浏览，结束保存后再下载录像。

    画质、声音与性能

    照片与录像使用独立分辨率。JPEG 数值越低，画质越高，文件也越大。录像结束后再修改参数。

    240 MHz 是芯片官方最高频率。降低频率可能降低帧率并延长登录等待。数字增益同时放大声音与底噪；音量失真时降低增益。

    开启省电后，无预览、拍照或录像达到空闲时限会暂停摄像头与麦克风，并启用 Wi-Fi 节电。WireGuard 和管理页面保持可访问，下一次拍摄自动唤醒。

    定时拍照

    事件监测与定时拍照不能同时开启，请先停止当前模式。

    间隔为 5 秒至 7 天。每次开始创建独立文件夹；重启后停止。运行期间锁定拍摄参数。

    后台视频转换

    保留原分辨率、时长和声音。MP4 校验成功后删除 AVI，即使 MP4 更大。事件监测和定时拍照期间暂停转换。

    蓝牙管理

    使用 nRF Connect 配对后管理设备。PIN 与管理员密码独立；USB 输入 BLE PIN 可找回。

    WireGuard

    导入单个服务器配置，先测试远程访问。全隧道可在连接成功后单独开启；更改需要局域网确认，未确认会自动回退。

    远程访问保留普通上网。全隧道通过服务器上网，断线时阻止公网直连，局域网仍可访问。需要 0.0.0.0/0、DNS IPv4、MTU 不超过 1420，以及服务器转发和 NAT。IPv6 不进入隧道；全隧道下阻止 IPv6 公网直连。

    逐项填写配置

    密钥不会回显或导出。导入后请在下方 Wi-Fi 设置中，从设备的局域网地址确认试运行；未确认会自动回退。

    Wi-Fi 设置

    新网络会先试运行。请在连接成功后确认；失败时自动恢复当前配置。

    账户与安全

    修改管理员密码后，所有已登录设备需要重新登录。Wi-Fi 和 WireGuard 配置会保留。

    管理员密码需至少 10 个字符，最多 128 个 UTF-8 字节。

    固件更新

    选择本项目生成的 firmware.bin，并提供配套 SHA-256。更新时摄像机暂停，完成后自动重启，请重新登录。
