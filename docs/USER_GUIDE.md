## 480p 事件抓拍与媒体删除

在预览下面选择低、中或高灵敏度，点击“开启事件抓拍 · 480p”。设备会
持续监测，检测到画面变化才保存独立的带声音 AVI 片段。静止确认一秒期间
的画面和声音暂存在内存：恢复运动就继续同一片段，确认静止就丢弃尾部。
检测约每 250 毫秒一次，短于检测确认窗口的动作可能错过；没有预录缓存。
画面整体均匀变亮和轻微噪声会被过滤，树叶、影子等局部变化仍可能触发。

此模式临时固定 640×480、目标 15 FPS。页面显示监测中、事件保存中和已保存
数量。点击“停止事件抓拍”后，设备恢复你原来保存的录像参数和空闲省电。
监测期间摄像头保持运行；退出登录和关闭页面仍会继续监测。重新启动后
处于关闭状态。请先停止抓拍，再拍高分辨率照片、修改参数、手动录像或 OTA。

每个媒体文件左侧均有复选框。“选择已加载文件”选择当前列表已经显示的
文件；加载更多后可以继续勾选。切换日期或刷新列表会清空选择。
“删除所选”确认后只删除勾选的文件。“删除全部照片和录像”会先读取全部
日期和分页，然后显示总数量并请你确认，范围包括其他日期和未显示的文件。
删除无法撤销。扫描不完整时不会开始清空；中断后页面会显示已完成数量。
录像、抓拍监测或下载期间，删除操作会被拒绝。配置和其他 SD 文件会保留。

## 登录与访问

同一局域网打开 **http://192.168.1.181/**，输入你选定的管理员密码。
DHCP 地址可能改变，请以路由器或设备的当前地址为准。
页面、字体、脚本和样式都来自固件，无需 CDN。
右上角可切换中文、English、Deutsch，刷新后保留语言；浏览器只保存语言代码。

默认 240 MHz 时登录计算约需 35–50 秒；较低频率需要更久。请等待页面结果；摄像和状态服务在密码计算期间
仍可运行。不同设备有独立会话；“退出登录”会撤销当前会话并停止它的预览
或文件下载。重新启动或更新固件后需要重新登录。
80 MHz 实测一次登录约 168 秒；页面的等待期限已延长，推荐日常保持 240 MHz。

WireGuard 已连接时，另一台同服务器的 peer 打开
**http://10.8.0.5/**。服务器需允许 peer 之间的访问。你已验证正式登录、拍照
与录像；电脑也已从此地址完成固件更新和新版 Chrome 界面检查。
WireGuard 提供“远程访问”和“IPv4 全隧道”两个模式。远程访问保留 Wi-Fi
普通上网和 DHCP DNS；全隧道让非局域网的 IPv4 请求通过服务器上网。
全隧道断线时阻止公网直连，局域网管理、拍照和录像保持可用。

在设备局域网地址展开“WireGuard 远程访问”，选择连接模式并点击“测试连接模式”。
全隧道需要配置包含 `0.0.0.0/0`、可用的 IPv4 DNS、MTU 不超过 1420，
并且服务器已经开启 IPv4 转发和 NAT。等待真实出口验证成功，再在下方点击
“确认此网络可用”；取消、超时或试运行中重启会恢复之前的配置。
导入配置先测试远程访问，连接成功后再选择全隧道。更改模式只修改该选项，
不会改动密钥、Wi-Fi、管理员账户或媒体文件。

“全隧道出口已验证”表示设备的普通 HTTPS 请求已通过隧道，页面显示出口
IPv4 和上次验证的秒数。验证会定期刷新；断线、失败或过期时不显示成功。
公网验证服务暂时不可用时，局域网仍可访问。IPv6 不进入 WireGuard 隧道；
全隧道模式阻止 IPv6 公网直连，保留本地链路管理。

## 修改管理员密码

展开“账户与安全”，填写当前密码、新密码和确认新密码，点击“修改密码”。
新密码需至少 10 个字符、最多 128 个 UTF-8 字节，且与当前密码不同。
提交后输入框会清空，请等待结果；低频模式需要更久。
成功后所有设备的旧登录都会失效，请用新密码重新登录。
Wi-Fi、WireGuard、摄像参数和已有媒体会保留。
验证期间退出当前登录会取消尚未保存的修改。
本机 `.tools/private/admin-password.txt` 是测试工具使用的密码文件，网页改密
不会自动修改电脑上的文件；以后运行这些工具时需保持文件内容与设备密码一致。

## 拍照、录音录像和文件

“开启预览”显示实时 MJPEG；“查看单张画面”只查看，不写卡。
“拍照并保存”把新 JPEG 写入 SD 卡，随后可在媒体列表预览、下载或删除。

“开始录制”手动创建含视频和声音的 AVI。“停止录制”后请等待保存完成。
录像期间拒绝重启、OTA、录像文件下载和删除。设备不会在开机时自动录像。
默认 VGA 640×480、请求 15 FPS；实测约 13.9 FPS。
声音为 PDM 麦克风的 16 kHz、单声道、16 位 PCM。
默认麦克风增益已提高到 **4×（+12 dB）**。增益过高可能使大声输入失真，
可在“画质、声音与性能”中调整，再录一段试听。
选择“关闭（仅预览与拍照）”会实际停止麦克风输入。此时仍可拍照、预览，
开始录制前需重新开启麦克风；当前 AVI 录像流程要求音频输入。

媒体列表按日期分页。JPEG 可直接预览，AVI 下载后请用支持 MJPEG/PCM
的播放器打开。“改名”修改日期前缀后的名称，保留日期和扩展名，支持中英德
文字、数字、空格、下划线和连字符，最多 64 个 UTF-8 字节（中文通常每字
3 字节）。正在录制或下载的文件不能改名；同名不会覆盖。删除会先弹出确认，且不能恢复。
日常固件关闭自动格式化和自动删除；不要在录像、保存或下载时拔卡。
请使用 FAT32 卡。当前卡已按你授权格式化并通过读写测试。
开机挂载失败时，内置管理页面和 NVS 账户/网络仍可用，拍摄保存会明确拒绝；
模拟缺挂载和实际断电取卡后的登录/摄像/WG/重启已实测。
修复了缺少旧配置文件时不必要的亮度采样报错；手动模式不运行旧帧分析。
实际断电插回后，79 个原媒体保留，新照片和带声音录像的保存、完整下载及解码
也通过；满卡/损坏卡仍未验证，见 [SD 恢复](STORAGE_RECOVERY.md)。

## 画质、状态和省电

展开“画质、声音与性能”，更改后点击“保存参数”。参数保存在开发板中，
重启和正常 OTA 后继续使用。“恢复推荐参数”只填入表单，需要保存才生效。
保存会停止当前预览；录像和收尾期间请先等待结束再修改。

| 项目 | 建议与行为 |
| --- | --- |
| 照片分辨率 | 默认 2048×1536，八档可选，已逐档验证实际 JPEG 尺寸；录像分辨率独立 |
| 录像分辨率 / FPS | 默认 640×480、目标 15 FPS；更高分辨率会增加负载，目标不保证达到 |
| JPEG 品质 | 数值越小压缩越少、文件越大；照片默认 8，录像默认 10 |
| 亮度 / 对比度 / 饱和度 | 范围 −2 到 +2，可从默认值逐项调整 |
| 白平衡 / 曝光 / 增益 | 支持自动及手动选项；关闭自动曝光/自动增益后相应手动输入可用 |
| 锐度 / 降噪 / 镜像等 | 根据实际场景调整；传感器参数不能增加镜头和像素本身的细节 |
| CPU 频率 | 80/160/240 MHz；默认 240 MHz 已是官方最高规格，低频可能降低性能 |
| SD 保留空间 | 默认保留 1024 MB；不足时拒绝开始新拍摄，已有媒体不会被自动删除 |
| 空闲省电 | 默认开启，120 秒无预览、拍照或录像后暂停摄像头/PDM，并启用 Wi-Fi modem sleep |

已登录但没有使用摄像功能也可进入待机；状态轮询不阻止待机。WireGuard 和
管理页保持可访问，下一次拍照、预览或录像自动唤醒。没有启用会切断网络的
deep sleep；实际耗电尚未用电表测量。
OV3660 待机时让传感器进入软件省电模式，保留摄像驱动与缓存，避免反复重建。
因此待机不会增加可用 PSRAM。唤醒会丢弃旧帧，确认新帧后再恢复拍摄；
CPU 保持你选择的频率。实际麦克风输入已停止，网络和管理入口继续可用。

CPU 占用是两核现有任务运行计数的两秒估计，不新增忙循环。RAM 显示内部
可分配堆的占用率，PSRAM 单独显示；它们与全部物理 SRAM 不完全相同。
Wi-Fi 同时显示 dBm 和优秀/良好/一般/较差/很差；分界约为 −50/−60/−70/−80
dBm，仅用于帮助判断信号，不能保证带宽。

## Wi-Fi、WireGuard 与恢复

Wi-Fi 设置提交新名称和密码后先试运行。连接成功后，从设备的实际
局域网地址登录，点“确认此网络可用”。失败约 60 秒会恢复旧配置；
未在 90 秒内确认或试运行中重启，也会保留旧配置。

WireGuard 设置可选择 `.conf` 文件或粘贴内容，点击导入后输入区会清空。
也可展开“逐项填写配置”。只支持一个服务器 peer。密钥不回显、不导出；
原始配置请自己保管。“重连 WireGuard”保留当前配置和 Wi-Fi。
成功连接后，在下方网络设置中从局域网确认试运行。
“测试关闭 WireGuard”同样需要确认，否则自动恢复旧配置。
“清除 WireGuard 配置”先建立不含密钥的候选配置，局域网确认后才保存；
确认前可取消。清除后重新导入原始 `.conf` 即可测试并确认恢复连接。

网络持续失败时，设备开启恢复热点 **XIAO-Camera-084C**，连接后打开
**http://192.168.4.1/**。已有账户仍需要密码。首次未设置账户时，热点页
可创建管理员并设置 Wi-Fi；连接家庭 Wi-Fi 后从实际 LAN 地址确认。
网络恢复稳定后热点关闭。

## 更新固件

构建命令和 USB 上传见 [BUILD.md](BUILD.md)：

```powershell
python scripts/pio.py run -e xiao-appliance
```

更新页面选择 `.pio/build/xiao-appliance/firmware.bin`，同时选择配套
`firmware.bin.sha256` 或填入其 SHA-256。使用本项目生成的应用镜像，
不要选择 factory 镜像或测试 fixture。停止录制后上传，保持供电和网络。
固件校验完成后自动重启，管理服务健康检查失败时会回到前一个有效分区。
SHA-256 检查上传完整性，不代表固件签名。详见 [OTA.md](OTA.md)。

本地 USB 为 COM3。正常上传保留 NVS 配置和 SD 文件；不要执行全片擦除。
